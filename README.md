# Kyrgyzest React · Reviews Refresh v9

Реализован новый интерактивный раздел отзывов с тремя вкладками:

1. **Guest Stories** — существующие девять авторов с Kyrgyzest.com, горизонтальная карусель сохранена.
2. **Google Reviews** — брендинг Google и прямая ссылка на оригинальный список отзывов; рейтинг и тексты не подделываются. Публичный рейтинг через обычный frontend невозможно надёжно подтягивать из Google без соответствующего API и разрешений.
3. **Tripadvisor** — **5.0 / 5 · 12 reviews** на дату проверки **24.10.2026**, три коротких дословных фрагмента реальных отзывов и ссылки на полные оригиналы. Числа — статический снимок, не live API.

## UX
- Вкладки с логотипами Google и Tripadvisor (Wikimedia Commons SVG по URL, с текстовым запасным отображением).
- Плавная смена панелей, состояние клавиатуры: стрелки влево/вправо, Home/End.
- Адаптивный дизайн, Remix Icon для интерфейсных иконок, корректный reduced-motion.
- Сохранены текущий hero, карта, галерея, секции и формы.

## Важно
- Google и Tripadvisor не предоставляют публичное бесключевое API для полноценного автоматического импорта всех отзывов. Для live-отображения потребуется серверная интеграция с разрешённым API/виджетом.
- Тексты ручных отзывов не выдуманы: в этой версии исходные карточки по-прежнему ведут на опубликованные отзывы; не заменяйте их пересказами.
- SVG-логотипы внешние и требуют интернет. Сайт сохраняет текстовые ярлыки, если загрузка заблокирована.
